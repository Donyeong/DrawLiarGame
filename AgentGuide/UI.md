# UI와 현지화 필수 규칙

- UI에는 사용자의 현재 판단과 행동에 필요한 정보만 표시한다. 작업 지시·구현 내용·플랫폼 지원 같은 개발 설명이나 장식용 안내 카드를 제품 문구로 넣지 않는다.
- 시작 화면의 브랜드 영역에는 로고만 사용하고 별도의 캐릭터 삽화·대사 카드를 넣지 않는다. 인증 후 로비에는 로고·브랜드 푸터·기본 인원 안내를 상시 표시하지 않는다.
- 공개 방 검색과 목록은 로비에서 제공한다.
- PC와 모바일은 브랜드·캐릭터·일러스트·폰트·버튼의 시각 스타일을 공유한다. 모바일은 배치·터치 영역·스크롤을 기기에 맞춘다.
- 스크롤 영역은 공통 `DrawSmoothScroll.Create`를 사용한다.
- 파츠 정의·가격·부위 교체는 공유 `AvatarParts`를 사용한다. 저장된 착용·구매 내역과 호환되도록 기존 파츠 비트와 상품 ID를 변경하거나 재사용하지 않는다.
- `Painter2D` 채움 경로의 첫 곡선은 `BezierCurveTo`를 사용한다.
- UI 고정 문구와 서식 문자열은 I2 Localization 기반 `DrawLocalization`을 거친다. 번역은 `UiTranslations.json`에서 수정하고 I2 소스는 자동 생성한다. 숫자·이름은 서식 인수로 분리한다.
- 닉네임·방 이름·채팅·사용자 주제·서버 제시어는 번역하지 않는다. 언어 변경으로 서버의 게임 데이터나 정답 판정을 바꾸지 않는다.
- 언어 변경은 현재 화면과 로고에 즉시 반영하고 선택을 저장한다. 로고와 폰트는 현재 언어에 필요한 것만 로드한다.
