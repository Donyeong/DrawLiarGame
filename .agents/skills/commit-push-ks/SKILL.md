---
name: commit-push-ks
description: 현재 작업 내용을 검토하고 적절한 커밋 메시지를 작성한 뒤 원격 저장소에 push한다.
---
현재 세션에서 수행한 작업과 git diff/status를 확인한다.

요청 범위의 파일만 스테이징하고 staged diff를 검토한 뒤 커밋하고 현재 브랜치의 원격으로 push한다. 관련 없는 기존 변경은 포함하지 않는다. 완료 후 커밋 해시와 push 결과를 간단히 보고한다.

- 특수문자를 사용하지 않고 쉼표로 구분한 나열형 형태로 최소한의 설명만으로 커밋 메시지를 작성한다.
- 이전 커밋 메시지들을 참고하여 유사한 형태로 커밋 메시지를 작성한다.
- 충돌이 있을 경우 AI 판단으로 머지하며, 문제가 있다고 판단 될 경우에만 작업자에게 확인 요청한다.
- 외부 프로젝트 명칭이나 참고 프로젝트를 커밋 메시지에 포함시키지 않는다.
- AI 작업용으로 사용된 검증용 임시코드, 이미지 같은 경우 변경내역에서 제거시킨다.
