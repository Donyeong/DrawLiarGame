상대 에이전트(Claude ↔ Codex)에게 작업 일부를 맡기거나 질문하고, 결과를 검증해 합친다.

## 호출

저장소 루트에서 `.agents/skills/agent-collab/scripts/Ask-Agent.ps1 -To claude|codex -Prompt '<브리프>'`를 실행한다.

- 상대의 최종 답변만 stdout으로 돌아온다. 긴 브리프는 파일로 써서 `-Prompt (Get-Content <파일> -Raw)`로 넘긴다.
- 호출은 수 분에서 수십 분 걸린다. 백그라운드로 실행하고 기다리는 동안 자기 몫을 진행한다.
- 중첩 호출은 스크립트가 2단계로 제한한다. 제한 오류가 나면 직접 처리한다. 결과를 받은 뒤 다시 호출하는 순차 반복은 제한이 없다.
- Codex 샌드박스 안에서 실행된 Claude는 Codex를 다시 부를 수 없다. Codex가 되부르기를 허용하려면 Claude 호출을 샌드박스 밖 실행으로 요청한다.

## 분업

- 몇 번의 도구 호출로 끝나는 작업은 맡기지 않는다. 대기 시간이 작업보다 길다.
- 서로 겹치지 않는 파일·씬 단위로 나눈다. 같은 파일을 동시에 고치면 서로 덮어쓴다.
- 스크립트 수정은 Unity 재컴파일을 일으켜 상대의 Unity MCP 호출을 실패시킬 수 있다. 컴파일이 끝난 뒤 다시 시도한다.

## 브리프

호출받은 쪽은 대화 맥락 없이 시작하므로 다음을 적는다.

- 목표와 배경, 이미 정한 결정
- 담당 파일·씬 범위와 "범위 밖은 수정하지 말고 커밋하지 말 것"
- 완료 기준과 돌려받을 내용(변경 파일, 검증 결과, 남은 문제)

## 결과

상대의 보고는 근거가 아니다. 호출한 쪽이 diff와 Unity 콘솔로 확인한 뒤 사용자에게 보고한다.
